# App de Bienvenida en Flask

Aplicación web simple en Python usando Flask.

## Ejecutar

1. Crear un entorno virtual:

```bash
python -m venv venv
```

2. Activar el entorno:

- Windows:
  ```bash
  .\venv\Scripts\activate
  ```

3. Instalar dependencias:

```bash
pip install -r requirements.txt
```

4. Ejecutar la app:

```bash
python app.py
```

5. Abrir en el navegador:

```
http://127.0.0.1:5000/
```
